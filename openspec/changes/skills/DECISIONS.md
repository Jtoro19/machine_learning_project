# Orchestrator Decisions — skills

Decisions taken autonomously during the unattended run, with rationale.

| # | Decision | Rationale |
|---|---|---|
| 1 | Route the preprocessing choice on **detected schema**, never on the shape of `--exclude`. | The original code reached the safe frozen path only when `--exclude` was empty or TTL-only. Every `SKILL.md` documents `--exclude id`, which failed that test and fell to a generic path returning the feature list unfiltered, so `label` (a perfect `attack_cat != "Normal"` predictor) entered the feature matrix. Passing nothing was safe; passing the careful flag leaked. Now `DROPPED_COLUMNS` and `TARGET_COLUMNS` are always subtracted on UNSW detection, so `--exclude` can only ever remove more columns. Verified on the real CSV: 39 features, no `label`, no `id`. |
| 2 | `_build_generic_preprocessor` lives in `src/nids/preprocessing.py` but stays **underscore-private**. | AGENTS.md requires shared preprocessing to live in `src/`, but `tests/test_leak_safety.py` is a hard AST guard (design Decision 5) requiring every public function in that module to take only `bool` parameters or none. A public function with `list[str]` parameters breaks that invariant. Private placement satisfies both rules; it is re-exported under its original name at its single call site. |
| 3 | **REVERSED, after external review.** I earlier instructed that the two unsupervised skills drop their train/test split, on the reasoning that unsupervised clustering has no held-out set to protect, and that the rationale be documented in their docstrings. The external reviewer rejected this: AGENTS.md states "Split first" unconditionally, the checklist item concerns the *operation* rather than the model that follows it, and pointing `--dataset` at the testing CSV would fit a `StandardScaler` and `OneHotEncoder` on the test partition. The reviewer's phrasing was decisive — *a docstring is not an amendment to the standard*. The split is restored in both skills, fitted on the training split only, and the exemption text removed. An agent does not amend the user's standard; only the user does. |
| 4 | UNSW-NB15 raw input is routed through the project's own cleaning steps before any fit. | `RareCategoryGrouper` documents that it must be fitted on the CLEANED training partition, because deduplication changes each column's row-count denominator and therefore which categories cross the 1% threshold. Reading raw with a bare `pd.read_csv` and fitting the frozen pipeline on it computes the rare-proto threshold over the wrong denominator, so the AGENTS.md rule was satisfied in name only. |
| 5 | Leakage guards raise `ValueError` rather than `assert`. | Bare asserts vanish under `python -O`. A guard protecting a rule the review checklist calls blocking must not be removable by an interpreter flag. |
